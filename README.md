# Piotr - Portfolio

Moja prosta strona portfolio dostępna na GitHub Pages.

## 📋 Zawartość

- ✨ Nowoczesny design z animacjami
- 📱 Responsywny layout
- 🎨 Piękne kolory i gradiencie
- ⚡ Szybka i lekka strona

## 🚀 Jak to działa?

Ta strona jest hostowana na GitHub Pages. Aby ją zobaczyć, odwiedź:
- https://smietanp.github.io
- https://smietanp.github.io/piotr-portfolio  (przekierowuje do głównej strony)

## 📝 Jak modyfikować stronę?

1. Edytuj `index.html` aby zmienić zawartość
2. Edytuj `style.css` aby zmienić wygląd
3. Wypchnij zmiany do GitHub: `git push`
4. Zmiany pojawią się online w ciągu kilku minut

## 🛠️ Lokalne testowanie

Możesz otworzyć `index.html` bezpośrednio w przeglądarce lub użyć dowolnego serwera lokalnego:

```bash
# Jeśli masz Python 3
python -m http.server 8000

# Jeśli masz Node.js
npx http-server
```

Następnie odwiedź `http://localhost:8000`
